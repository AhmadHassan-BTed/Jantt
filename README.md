### How It Works in 3 Steps
1. **Describe or Paste Anything in Plain English:** Type a goal, paste messy meeting notes, or ask to push deadlines, flag urgent risks, rebalance workloads, or add milestones.
2. **Review the Visual Diff Preview:** Jantt validates the AI's structured output against its strict schema and displays an exact **added / updated / removed diff preview** before touching your schedule. Zero surprise overwrites.

<details>
<summary><strong>Technical Details: Firebase RTDB Security Rules & Architecture</strong></summary>

- **GitHub-Only Auth:** Restricted to GitHub OAuth 2.0 (`read:user` scope). Automatically registers your verified GitHub handle into `/usernames/{username}` on first sign-in.
- **Security Rules (`database.rules.json`):**
  - `/users`: Indexed on `username` (`.indexOn: ["username"]`) for live prefix search; users may only write their own record.
  - `/usernames`: Atomic handle registration preventing username collisions.
  - `/user_rooms`: Fast dashboard listing of owned and shared cloud rooms.
  - `/rooms`: ACID transactions via `runTransaction` with 3-way CRDT reconciliation; only owners and editors can mutate plan state.
- **Optional Verification Gate:** `ENABLE_GITHUB_VERIFICATION_GATE` in `apps/playground/src/firebase/githubVerificationService.ts` (off by default) supports optional public follower/star checks using no additional OAuth scopes.

## Enterprise Scheduling Engine Under the Hood

Every calculation is written in strict TypeScript, verified by **1,290+ automated unit and integration tests** plus Python bridge tests:

| Algorithmic Engine | Standard / Math | What It Does |
| :--- | :--- | :--- |
| **Topological DAG Cascade** | $O(V + E)$ Tarjan SCC + topological sort | Cascades FS/SS/FF/SF links with lags/leads; respects `locked: true` milestones and isolates cycles safely without crashing. |
| **Working-Calendar CPM** | 2-pass AON + mixed-calendar longest-path | Computes ES, EF, LS, LF, Total Float, and Free Float on each task's resolved calendar (task -> person -> project -> Mon–Fri), honoring regional holidays (`US`, `UK`/`GB`, `EU`, `CA`, `AU`) and custom shifts without splitting mixed-calendar critical paths. |
| **Resource Leveling** | Priority- & float-aware capacity solver | Detects resource over-allocations per person/capacity and previews conflict-free schedule shifts before you apply them. |
| **Earned Value (EVM)** | ANSI/EIA-748 (`PV`, `EV`, `AC`, `CPI`, `SPI`, `EAC`, `TCPI`) | Tracks cost and schedule variance across your budget with honest forecasting. |
| **DCMA-14 Schedule Audit** | Selected DCMA 14-point checks (`A`–`F` grade) | Flags missing logic, leads, lags, non-FS links, hard constraints, high float (>44 working days), negative float, high duration, out-of-sequence progress, and broken links. |
| **PERT & Monte Carlo Risk** | $\mu = \frac{O + 4M + P}{6}$, 5,000+ stochastic runs | Computes probabilistic completion dates (P50 / P80 / P90), on-time deadline confidence, and task criticality index off the main thread in a Web Worker. |

## Developer and AI Agent Quickstarts

Embed Jantt into any web app, notebook, CLI pipeline, or AI agent in under 60 seconds:

### 1. React (`@jantt/react`)

```bash
npm install @jantt/react @jantt/core
```

```tsx
import { Jantt } from "@jantt/react";
import "@jantt/core/theme.css";

const projectData = {
  meta: { title: "Product Launch", calendar: "standard", showCriticalPath: true },
  categories: { core: { label: "Core Engineering", color: "#38BDF8" } },
  tasks: [
    { id: "t1", label: "Architecture RFC", category: "core", start: "2026-09-01", end: "2026-09-14", progress: 1.0 },
    { id: "t2", label: "Core Implementation", category: "core", start: "2026-09-15", end: "2026-10-15", dependsOn: "t1" }
  ]
};

export default function Timeline() {
  return <Jantt data={projectData} themeClassName="jantt-theme-dark" onCommit={(next) => console.log(next)} />;
}
```

### 2. Vue 3 (`@jantt/vue`)

```bash
npm install @jantt/vue @jantt/core
```

```vue
<script setup>
import { JanttTimeline } from "@jantt/vue";
import "@jantt/core/theme.css";

const props = defineProps(["plan"]);
const handleCommit = (updatedPlan) => console.log("Committed:", updatedPlan);
</script>

<template>
  <JanttTimeline :data="props.plan" theme-class-name="jantt-theme-dark" @commit="handleCommit" />
</template>
```

### 3. Svelte 4 / 5 (`@jantt/svelte`)

```bash
npm install @jantt/svelte @jantt/core
```

```svelte
<script>

  import "@jantt/core/theme.css";
  export let plan;

  const options = {

    onCommit: (next) => (plan = next)
  };
</script>

<div use:janttAction={{ data: plan, options }} style="width: 100%; height: 600px;" />
```
