# Support & Community

Welcome to the **Jantt** community! Here are the best ways to get help, ask questions, report issues, and connect with fellow developers.

---

## 💬 Getting Help

### 1. GitHub Discussions & Q&A
For architectural questions, integration help, feature discussions, and showing off what you built:
👉 [GitHub Discussions](https://github.com/AhmadHassan-BTed/Jantt/discussions)

### 2. Reporting Bugs
If you found a bug or unexpected behavior:
1. Search existing [Issues](https://github.com/AhmadHassan-BTed/Jantt/issues) to see if it's already reported.
2. If not, open a [Bug Report](https://github.com/AhmadHassan-BTed/Jantt/issues/new?template=bug_report.yml) with a minimal reproduction JSON payload.

### 3. Security Inquiries
For private security disclosures, please consult [SECURITY.md](file:///home/leech/Projects/JanntChart/SECURITY.md) or email [security@jantt.dev](mailto:security@jantt.dev).
