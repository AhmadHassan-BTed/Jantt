Jantt Privacy Policy

Last updated: November 2026

Jantt is a local-first planning application. Your plans, preferences, snapshots, and Bring Your Own Key (BYOK) AI credentials live in your own browser storage. There is no Jantt user account and no Jantt backend that stores your plan data.

1. Local-first storage

Plans, project lists, theme and layout preferences, version-history snapshots, and BYOK AI provider keys are stored in the browser (localStorage and IndexedDB) on the device you use. Jantt never uploads them to a Jantt server. Clearing browser storage removes them permanently.

2. BYOK AI Copilot

Prompts and plan snapshots are sent directly from your browser to the AI provider you choose (Gemini, OpenAI, Anthropic, Groq, DeepSeek, OpenRouter, Mistral, xAI, a custom HTTPS endpoint, or a local Ollama instance). They never pass through Jantt servers. Your provider API key is stored only in your browser.

3. Optional cloud rooms

Cloud collaboration is opt-in. When you create or join a cloud room, Jantt uses GitHub OAuth with the read:user scope for identity and Firebase Realtime Database solely to synchronize live plan edits between collaborators. Room data is stored in Firebase under the room you create. You can leave or delete a room at any time from within the app.

4. No ads and no tracking

Jantt contains no advertising, no third-party analytics trackers, and no sale of user data. The only network requests are to the services you explicitly use: Firebase, the GitHub API, your chosen AI provider, and remote plan imports you request.

5. Account and data deletion

You can delete your Jantt local data, cloud rooms, or optional sign-in account at any time:

  • Local device data: Clear site data (or uninstall the Android app / clear app storage) to permanently remove all local plans, notes, snapshots, preferences, and BYOK API keys stored on your device.
  • Cloud rooms: Open the Plan Manager or Cloud Room settings in Jantt and delete any cloud room you own. Deleting a room immediately removes the room document and revokes member access in Firebase.
  • Optional GitHub sign-in account: Sign out inside Jantt, revoke Jantt's OAuth authorization in your GitHub account settings, and email ahmadhassan.bted@gmail.com with your GitHub username to request immediate deletion of your Firebase authentication record and profile metadata.

Data deleted vs. retained: Upon account deletion, your Firebase authentication record, linked GitHub profile metadata (username, display name, user ID), and any cloud rooms you request to remove are permanently deleted within 7 days. No personal data is retained after deletion.
